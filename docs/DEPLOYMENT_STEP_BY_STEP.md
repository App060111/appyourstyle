# AppYourStyle veröffentlichen — Schritt für Schritt

## 1. ZIP entpacken
Entpacke diese ZIP vollständig.

Du musst im Hauptordner sehen:
- app
- components
- data
- lib
- docs
- seo
- package.json
- next.config.js

## 2. GitHub Repository öffnen
Gehe zu deinem Repository `appyourstyle`.

## 3. Dateien hochladen
Klicke:
Add file → Upload files

Ziehe ALLE Dateien und Ordner aus dem entpackten Hauptordner hinein.

Wichtig:
Nicht nur den Ordner app hochladen.
Nicht nur die ZIP hochladen.

## 4. Commit changes
Unten auf `Commit changes` klicken.

## 5. Vercel öffnen
Gehe zu vercel.com und melde dich mit GitHub an.

## 6. Projekt importieren
Add New Project → Repository `appyourstyle` auswählen → Import.

## 7. Deploy
Vercel erkennt Next.js automatisch.
Einfach Deploy klicken.

## 8. Live-Link prüfen
Nach 1–2 Minuten erhältst du:
https://appyourstyle.vercel.app

## 9. Wichtige Seiten prüfen
- /
- /faq
- /about
- /contact
- /privacy
- /imprint
- /terms
- /convert/nike/zara
- /shoe-size-converter
- /baby-size-guide

## 10. Vor Veröffentlichung wichtig
Impressum und Datenschutz mit echten Daten ergänzen.
