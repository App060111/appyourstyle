# Datenquellen & Grenzen

Die Daten sind MVP-orientiert und basieren auf allgemein öffentlich zugänglichen Größenlogiken:
- öffentlich sichtbare Hersteller-Size-Charts
- gängige EU/US/UK Schuhgrößenlogik
- allgemeine Baby-/Kindergrößen nach Körpergröße
- bekannte Fit-Tendenzen aus öffentlichen Produkt- und Größentabellen

Wichtig:
- Marken ändern Größen und Schnitte.
- Produktkategorien müssen später getrennt werden.
- Offizielle Tabellen sollten regelmäßig geprüft werden.
- Nutzerfeedback wird später die Genauigkeit erhöhen.
