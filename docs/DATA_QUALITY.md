# Datenqualität

Diese Version nutzt strukturierte Daten mit:
- sourceType: official / public / estimated
- confidenceScore
- fitType
- genderCategory
- category
- region
- updatedAt

Wichtig:
Nicht alle Werte sind offizielle Partnerdaten. Wo keine verlässliche offizielle Quelle eingebunden ist, wird `estimated` oder `public-reference` genutzt.
