# AppYourStyle

AppYourStyle ist eine KI-gestützte Fashion- und Größenplattform.

## Funktionen

- Größenempfehlungen zwischen Marken
- Outfit-KI
- Reise- und Anlass-Empfehlungen
- Mobile optimiert
- Fashion-KI Suche
- Footer mit Navigation
- FAQ & rechtliche Seiten
- KI Outfit-Ergebnisse
- Style-Logik & Komfort-Fokus

## Nutzung

1. Frage eingeben
2. Marken auswählen
3. Empfehlung suchen klicken
4. Ergebnis erhalten

## Technologie

- Next.js
- React
- Vercel
- OpenAI API

## Deployment

Deployment erfolgt über Vercel.
